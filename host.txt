  🆓 Free Hosting Options (Static HTML)                                                                                                                                                                                                                                                                                                                        
  1. GitHub Pages ⭐ RECOMMENDED                                                                                                                                                                                  - Free, no bandwidth limits                                                                                                                                                   
  - Custom domain support
  - Automatic HTTPS
  - Easy Git-based deployment
  - Steps:
    a. Create a GitHub account
    b. Create a new repository named risk-management-tool (or any name)
    c. Upload risk-management-tool.html to the repo
    d. Go to Settings → Pages
    e. Select branch (main) and folder (root)
    f. Your site will be at: https://username.github.io/risk-management-tool/
  - Best for: Simple, reliable, professional feel

  2. Netlify Drop ⭐ EASIEST

  - Just drag & drop folder
  - Instant live URL
  - Free SSL certificate
  - No account needed (but you can create one)
  - Steps:
    a. Go to app.netlify.com/drop
    b. Drag the folder containing risk-management-tool.html
    c. Get a random URL like random-name.netlify.app
    d. You can rename it later (requires account)
  - Best for: Quickest deployment, zero configuration

  3. Vercel

  - Also free, similar to Netlify
  - Excellent performance
  - Custom domains on free tier
  - Easy Git integration
  - URL: your-project.vercel.app
  - Best for: If you want to deploy from GitHub/GitLab

  4. Cloudflare Pages

  - Free, global CDN
  - Fast worldwide
  - Custom domains with free SSL
  - Git-based or direct upload
  - URL: your-project.pages.dev
  - Best for: Best performance globally

  5. Render.com

  - Free static hosting
  - Custom domains
  - No bandwidth limits
  - URL: your-project.onrender.com
  - Best for: Reliability, good for small projects

  6. Surge.sh (CLI tool)

  - Command-line deployment
  - Free subdomain
  - Very simple
  - Install: npm install -g surge
  - Deploy: surge ./ your-project.surge.sh
  - Best for: Developers comfortable with terminal
